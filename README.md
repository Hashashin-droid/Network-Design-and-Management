# Network-Design-and-Management

### Objectives
    1. To design a hierarchical network architecture that includes core, distribution, and access layers with a DMZ.
    2. To assign and label appropriate IP addressing schemes for internal networks, external networks, and DMZ segments.
    3. To explain and justify the use of BGR and BGP in connecting the internal network to external networks while ensuring security and scalability.
### Scenario
You are a network engineer of a company, who are assigned a task to design a secure enterprise network for a medium-sized organization. The design should consider internal services and public-facing applications as well.
### Task Instructions
You are required to draw a network diagram that meets the following requirements:
    1. Apply a hierarchical network design by clearly showing the Core, Distribution, and Access layers, and include a Demilitarized Zone (DMZ) for public services.
    2. Label all devices and links with appropriate IP addresses, including private IP addresses for the internal network and public IP addresses for the external network.
    3. Clearly differentiate the internal network and the external network (Internet) in the diagram.
    4. Include a Border Gateway Router (BGR) at the network edge and indicate the use of Border Gateway Protocol (BGP) for routing between the organization and the Internet Service Provider (ISP).
    5. Provide a written explanation and justification of your design, explaining how the hierarchical structure, DMZ placement, IP addressing, and use of BGR and BGP contribute to network performance, scalability, and security.
